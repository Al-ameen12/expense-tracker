# SpendWise
> **Current Status:** Phase 1 complete. Phase 2 in progress.

SpendWise is an all Expense Tracker that helps you track your spending habit.


## Project Roadmap
The project is divided into 5 phases

### Phase 1 — Core CLI (✓)
Log expense, view history, persist to JSON

### Phase 2 — Smarter CLI
Total spending, filter by category, delete an expense, input validation

### Phase 3 — Analytics
This is where pandas earns its place — monthly summaries, spending by category, trends. Your DataCamp work feeds directly into this.

### Phase 4 — Web
Convert to a Flask or Django backend, expose your functions as API endpoints, add a simple frontend. This is your backend engineering milestone.

### Phase 5 — Hosted
Deploy to Railway or Render, share a live link. SpendWise becomes a real product anyone can use.

## How to Run
1. Clone the repo: `git clone https://github.com/Al-ameen12/expense-tracker.git`
2. Navigate into the folder: `cd expense-tracker`
3. Run the app: `python expense_tracker.py`

## Technologies used so far:
Python, JSON, datetime

## Project Flow:
Collects and validates user input
Structures data with dictionaries and lists
Persists data to a file with JSON
Handles errors gracefully
